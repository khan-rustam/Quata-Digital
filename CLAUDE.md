# QuataDigital

Public marketing site, seven product pages, and the full internal cockpit for
QUATA Digital Enterprise (Bamenda, Cameroon) — all on a single API.

Fleet rules in [`../CLAUDE.md`](../CLAUDE.md) apply. This file covers only what is
specific to QuataDigital.

- Repo: `khan-rustam/Quata-Digital` · branch `main`
- Backend `0.3.0` · Frontend Next.js 16 / React 19

## Stack

| Layer | What |
|---|---|
| Backend | FastAPI · SQLAlchemy 2 · Alembic · JWT + TOTP 2FA |
| Frontend | Next.js 16 · React 19 · **Tailwind 4** · Radix UI primitives · Framer Motion |
| Tests | Playwright (`@playwright/test` in frontend) |

## Commands

```bash
docker compose up -d                      # postgres 16

cd backend && cp .env.example .env && uvicorn app.main:app --reload
cd frontend && npm install && npm run dev
npm run lint                              # eslint
```

Dev defaults to SQLite (`sqlite:///./quata.db`) with `SEED_ON_STARTUP=true`.

## Architecture notes

- The cockpit is wide: **57 route segments** and 19 route modules
  (`routes_admin*.py`, `routes_whatsapp.py`, `routes_devices.py`, `routes_ws.py`,
  `routes_security.py`, …). Search before adding a route file.
- **Device HMAC signing** is real and enforced: `DEVICE_REQUIRE_SIGNATURE`,
  `DEVICE_HMAC_HEADER`, `DEVICE_HMAC_TIMESTAMP_HEADER`, `DEVICE_HMAC_SKEW_SECONDS`.
  Don't disable it to make a client work — fix the client's signing.
- **Notification pipeline** has dedupe, retry, and a large-transaction threshold
  (`NOTIFY_DEDUPE_WINDOW_SECONDS`, `NOTIFY_MAX_ATTEMPTS`,
  `NOTIFY_LARGE_TX_THRESHOLD`), delivering to Telegram and WhatsApp. Changes here
  are easy to make noisy — check the dedupe window still holds.
- Lockout and rate limiting are configured, not incidental: `MAX_LOGIN_ATTEMPTS`,
  `LOCKOUT_MINUTES`, `RATE_LIMIT_LOGIN`, `RATE_LIMIT_PASSWORD_RESET`. Never relax
  these to unblock a test; use a test account or fixture instead.
- HR/attendance/leave models exist alongside marketing content — this repo is
  both the public site and the internal system. Don't assume a model is public.

## Deploy

`deploy.sh` runs the standalone Next server (not `next start`) under PM2, plus
`infra/cron/backup-postgres.sh`. `git log` shows repeated PM2 app-name and cwd
breakage — if a deploy silently doesn't go live, check the ecosystem file first.
Deploys touch production — ask first.
